DEG Summary Tables

The first two tables summarize the results of the infected and non-infected groups, using the diet 33 as a reference. This was done because it seems that the difference between the carb biased diet (33) and the reference was severe, whereas the difference between the protein-baised diet (83) and the reference had minor differences. This is based on observations from prior diet-infection experiments and is supported by data trends in this study. The model used in these groups simply accounted for diet, as infection status was negligible due to the separation of infected and non-infected specimens.

The third table displays genes that were differentially expressed both within infection and within one of the two biased diet groups (33 or 83). This table was made using the output of the full DESeq2 model, testing for interactive affects between diet and infection using the below formula.

\[model = ~Diet * Infection = Diet + Infection + Diet:Infection\]

The resulting csv files for both the 33 and 83 tests were then combined with a csv containing annotation information that I created using a custom script and the .gff file for S. gregaria from NCBI.

To view more information about a differentially expressed gene, hover over the regulation cell and the padj and log2 fold change values will appear.
