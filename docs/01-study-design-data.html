Purpose

Step 1 - Inspect inputs

Check that metadata, transcript-plus-exon counts, and annotation files are present.

Step 2 - Match samples

Confirm every count column has one diet and infection label.

Step 3 - Confirm design

Review group sizes and assigned-count depth before modeling.

This page records the input files, sample labels, experimental groups, and basic count-table checks used by downstream analyses. It is meant to be knitted before running DESeq2 pages so mismatched sample names or incomplete metadata are caught early.

The corrected experiment contains 45 sequenced libraries, but the biological analysis cohort contains 44 after excluding mapping-QC outlier 1044. Sample 1024 remains assigned to the infected diet-33 group. These conditions are checked explicitly below before any expression model is fitted.
