In addition to the standard DEG analysis applied to the previous tests, this model also underwent Surrogate Variable Analysis (SVA) to account for potential batch effects during data collection. We did not perform SVA on the previous analyses since those datasets were smaller.

DEG Summary Table

This table displays genes that were differentially regulated both within infection and within one of the two biased diet groups (33 or 83). This table was made using the output of the full DESeq2 model, testing for interactive affects between diet and infection using the below formula.

\[model = ~Diet * Infection = Diet + Infection + Diet:Infection\]

The resulting csv files for both the 33 and 83 tests were then combined with a csv containing annotation information that I created using a custom script and the .gff file for S. gregaria from NCBI.

To view more information about a differentially expressed gene, hover over the regulation cell and the padj and log fold change values will appear.
