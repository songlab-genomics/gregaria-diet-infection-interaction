Purpose

Step 1 - Process reads

Follow fastp, STAR, and competitive host-pathogen mapping on the HPC.

Step 2 - Count genes twice

Use -t transcript,exon -g gene_id for the primary analysis and -t exon -g gene_id for the matched sensitivity analysis.

Step 3 - Reproduce reports

Run the visible R Markdown code into new timestamped output folders.

This page is the reproducibility map for the project. It explains where inputs live, where new results are written, and how to rerun the workflowR pages without relying on hidden helper scripts.

Both count definitions use the same frozen 44-library analysis cohort and corrected metadata. Sample 1024 is infected diet 33; library 1044 was processed and retained in the QC audit but excluded from biological models. The two branches differ only in which annotation feature types are counted, so their DEG results can be compared directly.

RNA-seq workflow overview

This project starts from gene-level count files that were produced upstream on the HPC. The diagram below separates the HPC preprocessing steps from the workflowR analyses in this repository, so it is clear which part maps reads to the Schistocerca gregaria reference and which part tests diet, infection, and diet-by-infection expression patterns.

The important handoff for this repository is the count matrix. STAR produces the alignments and featureCounts assigns paired fragments with -t transcript,exon -g gene_id. The workflowR pages then merge and check those counts, remove the loci listed in gregaria_rrna_list.txt, and use the rRNA-filtered matrix for QC, differential expression, annotation enrichment, and publication figures.

Analysis contract

The current analysis pages follow this pattern:

  1. Put editable file paths, thresholds, and model choices in the page params.
  2. Load metadata and counts directly in the Rmd.
  3. Check that count columns match metadata before modeling.
  4. Write derived tables and figures to a new folder under output/rmd_runs/.
  5. Save sessionInfo() in the same folder as the results.

This keeps the manuscript figures reproducible while leaving the older scripts available for comparison.
