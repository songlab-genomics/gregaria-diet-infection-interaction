The important handoff for this repository is the count matrix. The original STAR alignment and gene-counting steps produce per-sample count files; the workflowR pages then merge and check those counts, remove the loci listed in gregaria_rrna_list.txt, and use the rRNA-filtered matrix for QC, differential expression, annotation enrichment, and publication figures.

Analysis contract

The current analysis pages follow this pattern:

  1. Put editable file paths, thresholds, and model choices in the page params.
  2. Load metadata and counts directly in the Rmd.
  3. Check that count columns match metadata before modeling.
  4. Write derived tables and figures to a new folder under output/rmd_runs/.
  5. Save sessionInfo() in the same folder as the results.

This keeps the manuscript figures reproducible while leaving the older scripts available for comparison.
