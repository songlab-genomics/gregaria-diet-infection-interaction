fat body RNA-seq / diet / fungal challenge

Fat body diet-infection RNA-seq analysis

This workflowR site retains all 44 fat-body samples and presents two parallel views of the same experiment. The all-scaffold branch preserves the complete host-reference signal; the placed-chromosome branch provides the conservative foreground used for the current publication figures. Outlier-removal analyses are archived as sensitivity checks rather than treated as competing results.

How To Read This Site

Start with the shared design, workflow, and QC pages. Then choose one analysis scope and keep that scope consistent through DEG testing, overlap, catalogue, and enrichment. The placed-chromosome branch is the current primary paper analysis; the all-scaffold branch shows how much of the signal depends on loci whose assembly placement is unresolved. Both retain every sample.
