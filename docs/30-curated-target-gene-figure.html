Purpose

This page follows a fixed set of immune and protein-anabolism genes through two matched views: genes on the main Schistocerca gregaria chromosomes and the complete all-scaffold set used in the original curated figure. The biological categories come from the supplied workbook, while every differential-expression status is recalculated from the current competitive-host DESeq2 results.

Step 1 - Match genes

Join the curated IDs to the GFF annotation and official assembly placement.

Step 2 - Recalculate status

Apply the same DEG thresholds to every target and contrast.

Step 3 - Compare scopes

Read the main-chromosome and complete all-scaffold panels side by side.

A target is shown as N.S. when it does not meet both padj < alpha and |log2FC| >= lfc_threshold. Keeping the target set fixed makes changes in the category percentages directly comparable across contrasts and placement classes.

The label below each facet reports the number of curated target genes in the denominator, not the number of DEGs. Differential-expression status is recalculated from the current transcript-plus-exon model, so a target can move into or out of significance even though restricting the target list to main chromosomes can only reduce its size.

path_ancestors <- function(path) {
  path <- normalizePath(path, mustWork = FALSE)
  ancestors <- path
  repeat {
    parent <- dirname(path)
    if (identical(parent, path)) break
    ancestors <- c(ancestors, parent)
    path <- parent
  }
  ancestors
}

latest_matching_dir <- function(root, pattern) {
  root <- resolve_path(root)
  candidates <- list.dirs(root, recursive = FALSE, full.names = TRUE)
  candidates <- candidates[grepl(pattern, basename(candidates))]
  if (length(candidates) == 0) {
    stop("No result folder matched ", pattern, " under ", root)
  }
  sort(candidates)[[length(candidates)]]
}

make_run_dir <- function(root, tag) {
  stamp <- format(Sys.time(), "%Y%m%d-%H%M%S")
  base <- file.path(resolve_path(root), paste0(tag, "_", stamp))
  candidate <- base
  suffix <- 1L
  while (dir.exists(candidate)) {
    suffix <- suffix + 1L
    candidate <- paste0(base, "_", suffix)
  }
  dir.create(candidate, recursive = TRUE, showWarnings = FALSE)
  candidate
}

Inputs and contrast direction

The workbook contains 163 unique target genes divided between immune and protein-anabolism categories. Its values came from the earlier all-sequence DEG catalogue. Here, the workbook supplies only gene membership and biological categories; the current log2 fold changes and adjusted p-values come from the latest placed/unplaced sensitivity run.

Within each diet, positive values mean higher expression in infected locusts. For across-diet comparisons, the sign is oriented to the higher-protein diet: 50 versus 33, 83 versus 33, and 83 versus 50. Thus, Upregulated always means higher expression in the first condition printed below the bar.

format_test_label <- function(p) {
  if (is.na(p) || p >= 0.05) return("N.S.D.")
  if (p < 0.0001) return("p < 0.0001")
  if (p < 0.001) return("p < 0.001")
  paste0("p = ", formatC(p, digits = 3, format = "f"))
}

calculate_figure_tests <- function(count_data) {
  set.seed(20260805)
  test_rows <- list()
  row_i <- 0L
  for (sheet_name in unique(count_data$source_sheet)) {
    for (category_name in unique(
      count_data$umbrella[count_data$source_sheet == sheet_name]
    )) {
      for (scope_name in unique(count_data$figure_scope)) {
        test_df <- count_data |>
          dplyr::filter(
            .data$source_sheet == sheet_name,
            .data$umbrella == category_name,
            .data$figure_scope == scope_name
          ) |>
          tidyr::complete(
            x_order = 1:3,
            status = c("Upregulated", "N.S.", "Downregulated"),
            fill = list(n_genes = 0)
          ) |>
          dplyr::arrange(.data$x_order, match(
            .data$status,
            c("Upregulated", "N.S.", "Downregulated")
          ))

        count_matrix <- matrix(test_df$n_genes, nrow = 3, byrow = TRUE)
        count_matrix <- count_matrix[, colSums(count_matrix) > 0, drop = FALSE]
        p_value <- NA_real_
        if (ncol(count_matrix) >= 2 && nrow(count_matrix) >= 2) {
          p_value <- suppressWarnings(stats::chisq.test(
            count_matrix,
            simulate.p.value = any(count_matrix < 5),
            B = 20000
          )$p.value)
        }

        row_i <- row_i + 1L
        test_rows[[row_i]] <- tibble::tibble(
          source_sheet = sheet_name,
          umbrella = category_name,
          figure_scope = scope_name,
          p_value = p_value,
          p_label = format_test_label(p_value)
        )
      }
    }
  }
  dplyr::bind_rows(test_rows)
}

The left panels summarize infection responses within each diet; the right panels compare infected locusts across diets. The exploratory chi-square labels summarize category composition and do not replace the gene-level DESeq2 tests.

The third composite isolates the 23 curated targets that meet the scaffold-origin page’s predefined homology-review rule. Of these, 3 have non-metazoan top hits in both BLASTn and DIAMOND; the remainder have conflicting evidence or protein-only support. These are provenance-review flags, not confirmed non-locust genes. Conserved proteins, incomplete reference representation, and short or divergent alignments can all produce a non-grasshopper top hit.
