Purpose

This page updates the coauthor-curated target-gene figure after the primary analysis was restricted to genes on the main Schistocerca gregaria chromosomes. The biological categories are preserved exactly from the supplied workbook, but every plotted differential-expression status is recalculated from the current competitive-host DESeq2 results.

The primary Figure 4 contains all curated targets that map to a nuclear chromosome. A retained target is shown as N.S. when it does not meet both padj < alpha and |log2FC| >= lfc_threshold in a particular contrast. This keeps the target set fixed rather than selecting a new subset separately for each comparison. Curated targets on unplaced scaffolds are documented below and exported for follow-up, but they are not included in the primary percentages.

path_ancestors <- function(path) {
  path <- normalizePath(path, mustWork = FALSE)
  ancestors <- path
  repeat {
    parent <- dirname(path)
    if (identical(parent, path)) break
    ancestors <- c(ancestors, parent)
    path <- parent
  }
  ancestors
}

latest_matching_dir <- function(root, pattern) {
  root <- resolve_path(root)
  candidates <- list.dirs(root, recursive = FALSE, full.names = TRUE)
  candidates <- candidates[grepl(pattern, basename(candidates))]
  if (length(candidates) == 0) {
    stop("No result folder matched ", pattern, " under ", root)
  }
  sort(candidates)[[length(candidates)]]
}

make_run_dir <- function(root, tag) {
  stamp <- format(Sys.time(), "%Y%m%d-%H%M%S")
  base <- file.path(resolve_path(root), paste0(tag, "_", stamp))
  candidate <- base
  suffix <- 1L
  while (dir.exists(candidate)) {
    suffix <- suffix + 1L
    candidate <- paste0(base, "_", suffix)
  }
  dir.create(candidate, recursive = TRUE, showWarnings = FALSE)
  candidate
}

Inputs and contrast direction

The workbook contains 163 unique target genes divided between immune and protein-anabolism categories. Its values came from the earlier all-sequence DEG catalogue. Here, the workbook supplies only gene membership and biological categories; the current log2 fold changes and adjusted p-values come from the latest placed/unplaced sensitivity run.

Within each diet, positive values mean higher expression in infected locusts. For across-diet comparisons, the sign is oriented to the higher-protein diet: 50 versus 33, 83 versus 33, and 83 versus 50. Thus, Upregulated always means higher expression in the first condition printed below the bar.

format_test_label <- function(p) {
  if (is.na(p) || p >= 0.05) return("N.S.D.")
  if (p < 0.0001) return("p < 0.0001")
  if (p < 0.001) return("p < 0.001")
  paste0("p = ", formatC(p, digits = 3, format = "f"))
}
