Purpose

This page follows a fixed set of immune and protein-anabolism genes through two matched views: genes on the main Schistocerca gregaria chromosomes and the complete all-scaffold set used in the original curated figure. The biological categories come from the supplied workbook, while every differential-expression status is recalculated from the current competitive-host DESeq2 results.

Step 1 - Match genes

Join the curated IDs to the GFF annotation and official assembly placement.

Step 2 - Recalculate status

Apply the same DEG thresholds to every target and contrast.

Step 3 - Compare scopes

Read the main-chromosome and complete all-scaffold panels side by side.

A target is shown as N.S. when it does not meet both padj < alpha and |log2FC| >= lfc_threshold. Keeping the target set fixed makes changes in the category percentages directly comparable across contrasts and placement classes.

The label below each facet reports the number of curated target genes in the denominator, not the number of DEGs. Differential-expression status is recalculated from the current exon-only model, so a target can move into or out of significance even though restricting the target list to main chromosomes can only reduce its size.

path_ancestors <- function(path) {
  path <- normalizePath(path, mustWork = FALSE)
  ancestors <- path
  repeat {
    parent <- dirname(path)
    if (identical(parent, path)) break
    ancestors <- c(ancestors, parent)
    path <- parent
  }
  ancestors
}

latest_matching_dir <- function(root, pattern) {
  root <- resolve_path(root)
  candidates <- list.dirs(root, recursive = FALSE, full.names = TRUE)
  candidates <- candidates[grepl(pattern, basename(candidates))]
  if (length(candidates) == 0) {
    stop("No result folder matched ", pattern, " under ", root)
  }
  sort(candidates)[[length(candidates)]]
}

make_run_dir <- function(root, tag) {
  stamp <- format(Sys.time(), "%Y%m%d-%H%M%S")
  base <- file.path(resolve_path(root), paste0(tag, "_", stamp))
  candidate <- base
  suffix <- 1L
  while (dir.exists(candidate)) {
    suffix <- suffix + 1L
    candidate <- paste0(base, "_", suffix)
  }
  dir.create(candidate, recursive = TRUE, showWarnings = FALSE)
  candidate
}

Inputs and contrast direction

The v21 workbook supplies the final curated gene membership and biological categories. Its stored fold changes are retained only for reconciliation; the figure itself recalculates every status from the current exon-only, competitive-host DESeq2 analysis. The main paper view then retains only genes assigned to nuclear chromosomes by the official assembly placement table.

Within each diet, positive values mean higher expression in infected locusts. For across-diet comparisons, the sign is oriented to the higher-protein diet: 50 versus 33, 83 versus 33, and 83 versus 50. Thus, Upregulated always means higher expression in the first condition printed below the bar.

      newly_significant_cells = sum(

format_test_label <- function(p) {
  if (is.na(p) || p >= 0.05) return("N.S.D.")
  if (p < 0.0001) return("p < 0.0001")
  if (p < 0.001) return("p < 0.001")
  paste0("p = ", formatC(p, digits = 3, format = "f"))
}

calculate_figure_tests <- function(count_data) {
  empty_result <- tibble::tibble(
    source_sheet = character(),
    umbrella = character(),
    figure_scope = character(),
    p_value = double(),
    p_label = character()
  )
  if (nrow(count_data) == 0) return(empty_result)

  set.seed(20260805)
  test_rows <- list()
  row_i <- 0L
  for (sheet_name in unique(count_data$source_sheet)) {
    for (category_name in unique(
      count_data$umbrella[count_data$source_sheet == sheet_name]
    )) {
      for (scope_name in unique(count_data$figure_scope)) {
        test_df <- count_data |>
          dplyr::filter(
            .data$source_sheet == sheet_name,
            .data$umbrella == category_name,
            .data$figure_scope == scope_name
          ) |>
          tidyr::complete(
            x_order = 1:3,
            status = c("Upregulated", "N.S.", "Downregulated"),
            fill = list(n_genes = 0)
          ) |>
          dplyr::arrange(.data$x_order, match(
            .data$status,
            c("Upregulated", "N.S.", "Downregulated")
          ))

        count_matrix <- matrix(test_df$n_genes, nrow = 3, byrow = TRUE)
        count_matrix <- count_matrix[, colSums(count_matrix) > 0, drop = FALSE]
        p_value <- NA_real_
        if (ncol(count_matrix) >= 2 && nrow(count_matrix) >= 2) {
          p_value <- suppressWarnings(stats::chisq.test(
            count_matrix,
            simulate.p.value = any(count_matrix < 5),
            B = 20000
          )$p.value)
        }

        row_i <- row_i + 1L
        test_rows[[row_i]] <- tibble::tibble(
          source_sheet = sheet_name,
          umbrella = category_name,
          figure_scope = scope_name,
          p_value = p_value,
          p_label = format_test_label(p_value)
        )
      }
    }
  }
  if (length(test_rows) == 0) empty_result else dplyr::bind_rows(test_rows)
}

build_figure4_panel <- function(
    status_count_data, sheet_name, scope_name, tag,
    show_y = TRUE, show_legend = FALSE, show_tests = TRUE) {
  panel_data <- status_count_data |>
    dplyr::filter(
      .data$source_sheet == sheet_name,
      .data$figure_scope == scope_name
    ) |>
    dplyr::mutate(
      umbrella = factor(
        .data$umbrella,
        levels = category_order[category_order %in% unique(.data$umbrella)]
      ),
      status = factor(
        .data$status,
        levels = c("Downregulated", "N.S.", "Upregulated")
      ),
      x_label = factor(
        .data$x_label,
        levels = unique(.data$x_label[order(.data$x_order)])
      ),
      outline = if (scope_name == "Within-diet infection response") {
        unname(diet_colors[as.character(.data$x_label)])
      } else {
        "#252525"
      }
    )

  panel_annotations <- panel_data |>
    dplyr::distinct(
      .data$umbrella, .data$p_label, .data$n_targets
    ) |>
    dplyr::mutate(
      p_label = if (show_tests) .data$p_label else "",
      x_label = factor(
        levels(panel_data$x_label)[[2]],
        levels = levels(panel_data$x_label)
      )
    )

  panel_title <- if (scope_name == "Within-diet infection response") {
    "Within-diet comparisons\n(Infected vs control)"
  } else {
    "Across-diet comparisons among infected\n(Higher protein vs lower protein)"
  }

  group_title <- dplyr::recode(
    sheet_name,
    "Immune" = "Immune-related",
    "Protein-Anabolism" = "Protein anabolism"
  )
  y_title <- if (show_y) {
    paste0(group_title, "\n\nPercentage of curated target genes (%)")
  } else {
    NULL
  }

  ggplot(panel_data, aes(x = x_label, y = percentage, fill = status)) +
    geom_col(
      aes(color = outline),
      width = 0.66, linewidth = 0.65
    ) +
    geom_text(
      data = panel_annotations,
      aes(x = x_label, y = 108, label = p_label),
      inherit.aes = FALSE,
      size = 3.3, fontface = "bold"
    ) +
    geom_text(
      data = panel_annotations,
      aes(x = x_label, y = -21, label = paste0("targets = ", n_targets)),
      inherit.aes = FALSE,
      size = 3.2
    ) +
    facet_wrap(
      ~ umbrella,
      nrow = 1,
      labeller = as_labeller(category_display)
    ) +
    scale_fill_manual(values = status_colors, drop = FALSE) +
    scale_color_identity() +
    scale_y_continuous(
      breaks = c(0, 50, 100),
      limits = c(-25, 113),
      expand = expansion(mult = c(0, 0))
    ) +
    coord_cartesian(clip = "off") +
    labs(
      tag = tag,
      title = panel_title,
      x = NULL,
      y = y_title,
      fill = NULL
    ) +
    theme_classic(base_size = 11) +
    theme(
      plot.tag = element_text(face = "bold", size = 17),
      plot.tag.position = c(0.005, 1.02),
      plot.title = element_text(
        face = "bold", size = 13, hjust = 0.5,
        margin = margin(b = 10)
      ),
      axis.title.y = element_text(size = 12, margin = margin(r = 7)),
      axis.text.y = if (show_y) {
        element_text(size = 10, color = "black")
      } else {
        element_blank()
      },
      axis.ticks.y = if (show_y) element_line() else element_blank(),
      axis.line.y = if (show_y) element_line() else element_blank(),
      axis.text.x = element_text(size = 10.5, color = "black", lineheight = 0.9),
      axis.ticks.x = element_blank(),
      strip.background = element_blank(),
      strip.text = element_text(
        face = "bold", size = 10.5, lineheight = 0.9,
        margin = margin(b = 7)
      ),
      panel.spacing.x = grid::unit(0.35, "lines"),
      legend.position = if (show_legend) "bottom" else "none",
      legend.text = element_text(size = 11),
      legend.key.size = grid::unit(4.5, "mm"),
      plot.margin = margin(12, 10, 40, 10)
    )
}

Both use the same current DESeq2 model, contrasts, thresholds, colors, and panel geometry. The left panels summarize infection responses within each diet; the right panels compare infected locusts across diets. The exploratory chi-square labels summarize category composition and do not replace the gene-level DESeq2 tests.

The third composite isolates the 0 curated targets that meet the scaffold-origin page’s predefined homology-review rule. Of these, 0 have non-metazoan top hits in both BLASTn and DIAMOND; the remainder have conflicting evidence or protein-only support. These are provenance-review flags, not confirmed non-locust genes. Conserved proteins, incomplete reference representation, and short or divergent alignments can all produce a non-grasshopper top hit.

All 0 targets are significant for infected diet 50 versus infected diet 33 because the scaffold-origin homology audit was itself constructed from the unresolved genes driving that contrast. That column documents the selection rule; it is not an independent confirmation. For this reason, the audit-only composite does not display the exploratory chi-square labels used for the fixed main and all-scaffold target sets.
