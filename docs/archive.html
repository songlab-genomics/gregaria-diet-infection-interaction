Why these pages are archived

The current analysis retains all 44 samples. Earlier pages that removed samples, tested alternative outlier sets, or used superseded count inputs are preserved here for provenance but are not part of the main results path. They should not be cited as the current DEG analysis.

The active outlier sensitivity page remains in the main Sensitivity and Validation menu because it documents how the sample filter changes the results without changing the adopted all-sample policy.

Superseded timestamped run folders were moved, not deleted. Their original locations, reasons for archival, and active replacements are recorded in output/archive/rmd_runs_20260806/MANIFEST.tsv.
