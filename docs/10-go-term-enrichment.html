Purpose

This page keeps the eggNOG-based functional enrichment with the conservative main-nuclear-chromosome differential-expression results. It uses the newest completed placed/unplaced analysis table on disk, retains only genes whose official assembly-derived class is Nuclear chromosome, and lifts eggNOG protein annotations onto the LOC... gene IDs in the count matrix, and tests infection DEG sets for enriched GO terms and KEGG pathways.

The key point is that this is a custom enrichment workflow for this reference: the foregrounds are current main-chromosome DEG sets, the background is the expression-filtered main-chromosome gene universe tested by DESeq2, and GO names/ontologies come from GO.db. Unplaced-scaffold and mitochondrial genes are intentionally excluded from both foreground and background here and remain available on the placement-sensitivity page.

The first enrichment section keeps the infection response non-directional, which asks what functions are over-represented among infection DEGs regardless of whether genes increase or decrease. A later section adds the direction-aware contrasts: infected-versus-control within each diet, diet contrasts among controls only, and diet contrasts among infected samples only.

Important KEGG scope note: the foreground genes and enrichment background are from the S. gregaria fat body count matrix, but the KEGG pathway IDs are koXXXXX KEGG Orthology reference pathways carried by eggNOG. These are not Insecta-only organism pathways. Some enriched labels can therefore be broad cross-domain maps or microbial/prokaryote-associated KEGG reference labels, even though the genes tested here are locust gene IDs. The pathway-scope table below flags those cases for interpretation.

Build eggNOG annotation maps

eggNOG reports annotations at the protein-query level, while DESeq2 reports uses LOC... gene IDs. The GFF provides the bridge from CDS protein IDs to gene IDs. Only expression-filtered genes tested in the competitive main-chromosome analysis are kept in the enrichment background.

read_emapper <- function(path) {
  cols <- c(
    "query", "seed_ortholog", "evalue", "score", "eggNOG_OGs",
    "max_annot_lvl", "COG_category", "Description", "Preferred_name",
    "GOs", "EC", "KEGG_ko", "KEGG_Pathway", "KEGG_Module",
    "KEGG_Reaction", "KEGG_rclass", "BRITE", "KEGG_TC", "CAZy",
    "BiGG_Reaction", "PFAMs"
  )
  tab <- read.delim(path, comment.char = "#", header = FALSE, sep = "\t",
                    quote = "", fill = TRUE)
  names(tab) <- cols[seq_len(ncol(tab))]
  tab |>
    dplyr::mutate(protein_id = stringr::str_extract(query, "XP_[0-9]+[.][0-9]+"))
}

parse_cds_gene_bridge <- function(path) {
  gff <- read.delim(path, comment.char = "#", header = FALSE, sep = "\t",
                    quote = "", stringsAsFactors = FALSE)
  names(gff)[1:9] <- c("seqid", "source", "type", "start", "end", "score",
                       "strand", "phase", "attributes")
  gff |>
    dplyr::filter(type == "CDS") |>
    dplyr::transmute(
      protein_id = stringr::str_match(attributes, "protein_id=([^;]+)")[, 2],
      gene_id = stringr::str_match(attributes, "gene=([^;]+)")[, 2]
    ) |>
    dplyr::filter(!is.na(protein_id), !is.na(gene_id)) |>
    dplyr::distinct()
}

get_kegg_pathway_names <- function(ids) {
  ids <- unique(ids)
  resolved <- setNames(rep(NA_character_, length(ids)), ids)

  if (requireNamespace("KEGGREST", quietly = TRUE)) {
    kegg_list <- tryCatch(
      KEGGREST::keggList("pathway", "ko"),
      error = function(e) character()
    )
    if (length(kegg_list) > 0) {
      live_ids <- sub("^path:", "", names(kegg_list))
      live_names <- sub(" - Reference pathway$", "", unname(kegg_list))
      live_names <- sub(" - Homo sapiens \\(human\\)$", "", live_names)
      resolved[intersect(ids, live_ids)] <- live_names[match(intersect(ids, live_ids),
                                                             live_ids)]
    }
  }

  fallback_ids <- intersect(ids, names(kegg_fallback_names))
  resolved[fallback_ids] <- ifelse(
    is.na(resolved[fallback_ids]),
    unname(kegg_fallback_names[fallback_ids]),
    resolved[fallback_ids]
  )
  resolved[is.na(resolved)] <- ids[is.na(resolved)]
  resolved
}

These foregrounds cover the full set of infection and diet comparisons. The figures use one column per contrast and use color/shape to show which side of the contrast carries the enriched genes. For infection contrasts, red means higher in infected samples and blue means higher in controls. For diet contrasts, red means higher in the first diet named in the column and blue means higher in the second diet. For example, in a 33 vs 83 column, blue points are the genes higher in diet 83.

The diet-only contrasts use the same competitive main-chromosome DESeq2 catalogue as the within-diet infection contrasts. make_directional_record <- function(set_id, family, comparison, direction,
                                    plot_label, genes, source_file) {
  data.frame(
    set_id = set_id,
    family = family,
    comparison = comparison,
    direction = direction,
    plot_label = plot_label,
    n_genes = length(genes),
    source_file = source_file,
    stringsAsFactors = FALSE
  )
}

add_directional_sets <- function(contrast_key, set_prefix, family,

  up_genes <- unique(tab$gene_id[tab$log2FoldChange > 0])
  down_genes <- unique(tab$gene_id[tab$log2FoldChange < 0])

  list(
    sets = list(

      stats::setNames(list(down_genes), paste0(set_prefix, "_down"))
    ) |>

      make_directional_record(
        paste0(set_prefix, "_up"), family, comparison, "Upregulated",

      ),
      make_directional_record(
        paste0(set_prefix, "_down"), family, comparison, "Downregulated",
        plot_label, down_genes, primary_results_file
      )
    )
  )
}

The fat body is central to immune defense, detoxification, lipid transport, and nutrient storage. classify_fat_body_candidate <- function(text) {
  text <- stringr::str_to_lower(text)

  )

    text,

    detox ~ "Detoxification / oxidative stress",
    endocrine_nutrition ~ "Endocrine / nutrient metabolism",

  )
}

run_enrichment <- function(genes, term2gene, term2name, universe) {
  genes <- unique(genes[genes %in% universe])
  if (length(genes) < 5) return(NULL)
  clusterProfiler::enricher(
    gene = genes,
    universe = universe,
    TERM2GENE = term2gene,
    TERM2NAME = term2name[, c("term", "name")],
    pvalueCutoff = 0.1,
    pAdjustMethod = "BH",
    qvalueCutoff = 0.2
  )
}

  pieces <- lapply(names(result_list), function(nm) {
