Purpose

This page tests the biological hypothesis in a targeted way using the 44-sample analysis cohort. The primary set contains 115 genes labelled Manual curation candidate for immune and protein-anabolism functions. A second, explicitly labelled tier adds eggNOG-supported candidate genes that are absent from the manual set but have relevant eggNOG descriptions, GO terms, KEGG annotations, or PFAM domains. The exact supporting annotation and matched rule are retained for every eggNOG-supported assignment.

  1. Protein and amino-acid availability that could affect fungal growth.
  2. Energy stores and starvation resistance in the locust fat body.
  3. Immune and stress responses during infection.

This is a candidate-gene screen, not a formal enrichment test. Darker candidate marks denote manual curation candidates and lighter marks denote eggNOG-supported candidates.

Step 1 - Define functions

Search insect-relevant immune, protein, lipid, carbohydrate, and detoxification terms.

Step 2 - Join DEGs

Match those annotations to current all-scaffold and chromosome-only contrasts.

Step 3 - Interpret diets

Compare how diet changes the infection response within each physiological theme.

Annotation table

eggNOG is protein-centered, while the count matrix uses LOC... gene IDs. The GFF file bridges protein IDs to gene IDs.

read_emapper <- function(path) {
  cols <- c(
    "query", "seed_ortholog", "evalue", "score", "eggNOG_OGs",
    "max_annot_lvl", "COG_category", "Description", "Preferred_name",
    "GOs", "EC", "KEGG_ko", "KEGG_Pathway", "KEGG_Module",
    "KEGG_Reaction", "KEGG_rclass", "BRITE", "KEGG_TC", "CAZy",
    "BiGG_Reaction", "PFAMs"
  )
  tab <- read.delim(path, comment.char = "#", header = FALSE, sep = "\t",
                    quote = "", fill = TRUE)
  names(tab) <- cols[seq_len(ncol(tab))]
  tab |>
    dplyr::mutate(protein_id = stringr::str_extract(query, "XP_[0-9]+[.][0-9]+"))
}

parse_cds_gene_bridge <- function(path) {
  gff <- read.delim(path, comment.char = "#", header = FALSE, sep = "\t",
                    quote = "", stringsAsFactors = FALSE)
  names(gff)[1:9] <- c("seqid", "source", "type", "start", "end", "score",
                       "strand", "phase", "attributes")
  gff |>
    dplyr::filter(type == "CDS") |>
    dplyr::transmute(
      protein_id = stringr::str_match(attributes, "protein_id=([^;]+)")[, 2],
      gene_id = stringr::str_match(attributes, "gene=([^;]+)")[, 2]
    ) |>
    dplyr::filter(!is.na(protein_id), !is.na(gene_id)) |>
    dplyr::distinct()
}

                             stringr::regex(term$pattern, ignore_case = TRUE))
  if (!any(hit)) return(NULL)
  annotation[hit, ] |>
    dplyr::transmute(
      gene_id, Preferred_name, Description, PFAMs,
      GOs, KEGG_ko, KEGG_Pathway,
      theme = term$theme,
      term_group = term$term_group,
      matched_pattern = term$pattern,
      matched_keyword = stringr::str_extract(

latest_dir <- function(pattern) {
  dirs <- list.dirs(results_root, recursive = FALSE, full.names = TRUE)
  dirs <- dirs[grepl(pattern, basename(dirs))]
  if (length(dirs) == 0) stop("No output folder matched: ", pattern)
  dirs[which.max(file.info(dirs)$mtime)]
}
