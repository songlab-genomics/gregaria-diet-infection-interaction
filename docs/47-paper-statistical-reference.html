Purpose

This page is the statistical map for the paper. It brings the model formulas, decision thresholds, current results, and biological interpretation into one place without replacing the full analysis pages. The aim is to make every reported statement easy to trace from an input table to an R model and then to a cautious conclusion.

Step 1 - Define the question

Identify the response variable, experimental terms, and analysis population.

Step 2 - Fit the model

Use the model appropriate for proportions, mass, counts, or compositions.

Step 3 - Report the evidence

Pair an effect size or test statistic with its uncertainty and P value.

Step 4 - Interpret carefully

State what the result supports and what the design cannot establish.

format_p <- function(x) {
  ifelse(
    is.na(x), "NA",
    ifelse(x < 0.001, formatC(x, format = "e", digits = 2),
           formatC(x, format = "f", digits = 3))
  )
}

Mapping quality

Question

Did diet, infection treatment, or their interaction affect the percentage of reads mapping to the locust reference? Mapping percentages are bounded between 0 and 100, so the proportions were logit-transformed before fitting Gaussian linear models.

run_mapping_model <- function(data, metric) {
  proportion <- pmin(pmax(data[[metric]] / 100, 1e-6), 1 - 1e-6)
  data$mapping_logit <- qlogis(proportion)

  factorial <- stats::lm(mapping_logit ~ Diet * Treatment, data = data)
  interaction_test <- stats::drop1(
    factorial, scope = ~ Diet:Treatment, test = "F"
  )

  additive <- stats::lm(mapping_logit ~ Diet + Treatment, data = data)
  main_tests <- stats::drop1(additive, test = "F")

  data.frame(
    mapping_definition = metric,
    interaction_p = interaction_test["Diet:Treatment", "Pr(>F)"],
    diet_p = main_tests["Diet", "Pr(>F)"],
    infection_p = main_tests["Treatment", "Pr(>F)"]
  )
}

run_mapping_mass_test <- function(data, metric) {
  spearman <- stats::cor.test(
    data$mass_g, data[[metric]], method = "spearman", exact = FALSE
  )
  data$mapping_logit <- qlogis(
    pmin(pmax(data[[metric]] / 100, 1e-6), 1 - 1e-6)
  )
  adjusted <- stats::lm(
    mapping_logit ~ mass_g + Diet + Treatment, data = data
  )
  adjusted_test <- stats::drop1(adjusted, test = "F")
  data.frame(
    mapping_definition = metric,
    spearman_rho = unname(spearman$estimate),
    spearman_p = spearman$p.value,
    adjusted_mass_p = adjusted_test["mass_g", "Pr(>F)"]
  )
}

Differential expression

Why raw counts are the model input

DESeq2 does normalize before testing. Raw integer counts are supplied to the negative-binomial model, and DESeq2 estimates sample-specific size factors by its median-of-ratios method. Variance-stabilized counts are used only for PCA and heatmaps because they are designed for distances and visualization, not for the count likelihood used by differential-expression tests.

Full factorial model

The full model asks whether the infection response changes with diet:

dds <- DESeq2::DESeqDataSetFromMatrix(
  countData = counts[keep_genes, ],
  colData = metadata,
  design = ~ Diet + Treatment + Diet:Treatment
)
dds <- DESeq2::DESeq(
  dds, minReplicatesForReplace = Inf, quiet = TRUE
)

# Example: diet 83 changes the infection response relative to diet 50.
res_interaction_83 <- DESeq2::results(
  dds,
  name = "Diet83.TreatmentInfected",
  alpha = 0.05,
  cooksCutoff = FALSE
)

The code above is executed in Main-chromosome interaction model. With diet 50 and controls as reference levels, the main treatment coefficient is the infected-versus-control response in diet 50. Interaction coefficients measure how that response differs in diets 33 or 83.

GO and KEGG enrichment

Test and background

For each DEG set, an over-representation test asks whether a GO term or KEGG reference pathway contains more DEGs than expected from the annotated genes in the expression-tested background. Upregulated and downregulated genes are combined in the main enrichment views. Enrichment does not test whether every gene in a term changes in the same direction.

run_enrichment <- function(genes, term2gene, term2name, universe) {
  genes <- unique(genes[genes %in% universe])
  if (length(genes) < 5) return(NULL)

  clusterProfiler::enricher(
    gene = genes,
    universe = universe,
    TERM2GENE = term2gene,
    TERM2NAME = term2name[, c("term", "name")],
    pvalueCutoff = 0.1,
    pAdjustMethod = "BH",
    qvalueCutoff = 0.2
  )
}

Result and interpretation. The conservative phase-reference set contained 357 genes shared between head and thorax, and 123 of these also occurred among the fat-body infection DEGs.
