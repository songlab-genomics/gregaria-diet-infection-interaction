Purpose

Step 1 - Gather evidence

Combine assembly placement, Kraken, BLASTn, DIAMOND, and cross-locust homology.

Step 2 - Classify support

Separate host-supported, ambiguous, and unresolved unplaced loci.

Step 3 - Plan follow-up

Preserve uncertain candidates for validation without mixing them into the primary host set.

This page asks whether the unplaced Schistocerca gregaria assembly scaffolds carrying many differentially expressed genes (DEGs) have independent evidence of locust origin. The audit itself does not relabel an unresolved scaffold as a contaminant. Following this review, the primary analysis now uses chromosome-assigned genes as its primary hypothesis family and preserves unplaced genes as an explicit sensitivity analysis on the placed/unplaced analysis page.

Evidence boundary: this is a focused origin audit of the 948 genes on 59 unresolved scaffolds that contribute to the infected diet 33 versus diet 50 contrast. BLASTn and DIAMOND results are now included. Similarity to a non-metazoan sequence is treated as a review flag, not as proof that a gene or scaffold is microbial.

The evidence combines:

  1. scaffold sequence and RefSeq gene-annotation metrics;
  2. Kraken2 classification against PlusPF;
  3. NCBI Foreign Contamination Screen (FCS) flags distributed with the assembly;
  4. whole-scaffold alignments to three related Schistocerca assemblies;
  5. BLASTn searches of gene regions against NCBI core_nt; and
  6. DIAMOND searches of predicted proteins against NCBI clustered_nr.

Cross-species support uses only minimap2 alignments with mapping quality at least 20 and divergence-derived nucleotide identity at least 70%. This avoids counting numerous ambiguous repetitive alignments as independent evidence of host conservation.

BLASTn and DIAMOND origin audit

The homology search produced one important technical result that must be corrected before biological interpretation. The raw BLASTn output contains exact matches to taxid 7010, S. gregaria, even though that taxid was excluded in the search command. If those self-hits are allowed to define the best bit score, almost every external match falls outside the retained 5% score tier.

The code below therefore removes taxid 7010 before calculating the best external score for each gene. It then retains external hits whose bit score is at least 95% of the best remaining score. DIAMOND did not retain taxid 7010 and is summarized from its transferred top-hit table.

hit_fields <- c(
  "qseqid", "qlen", "sseqid", "staxids", "pident", "length",
  "qcovhsp", "evalue", "bitscore", "stitle"
)

classify_broad_group <- function(lineage, scientific_name) {
  value <- paste(lineage, scientific_name)
  dplyr::case_when(
    stringr::str_detect(value, "(^|;)Schistocerca(;| |$)") ~ "Schistocerca",
    stringr::str_detect(value, "(^|;)Acrididae(;|$)") ~ "Other Acrididae",
    stringr::str_detect(value, "(^|;)Orthoptera(;|$)") ~ "Other Orthoptera",
    stringr::str_detect(value, "(^|;)Arthropoda(;|$)") ~ "Other Arthropoda",
    stringr::str_detect(value, "(^|;)Metazoa(;|$)") ~ "Other Metazoa",
    stringr::str_detect(value, "(^|;)Fungi(;|$)") ~ "Fungi",
    stringr::str_detect(
      value, "(^|;)(Viridiplantae|Streptophyta)(;|$)"
    ) ~ "Plants",
    stringr::str_detect(value, "(^|;)Bacteria(;|$)") ~ "Bacteria",
    stringr::str_detect(value, "(^|;)Archaea(;|$)") ~ "Archaea",
    stringr::str_detect(value, "(^|;)Viruses(;|$)") ~ "Viruses",
    stringr::str_detect(value, "(^|;)Eukaryota(;|$)") ~ "Other Eukaryota",
    TRUE ~ "Other/unclassified"
  )
}

collapse_group_support <- function(groups) {
  metazoan <- groups %in% c(
    "Schistocerca", "Other Acrididae", "Other Orthoptera",
    "Other Arthropoda", "Other Metazoa"
  )
  non_metazoan <- groups %in% c(
    "Fungi", "Plants", "Bacteria", "Archaea", "Viruses",
    "Other Eukaryota"
  )
  if (any(metazoan) && any(non_metazoan)) {
    return("Mixed metazoan/non-metazoan")
  }
  if (any(groups %in% c(
    "Schistocerca", "Other Acrididae", "Other Orthoptera"
  ))) {
    return("Locust/orthopteran")
  }
  if (any(groups == "Other Arthropoda")) return("Other arthropod")
  if (any(groups == "Other Metazoa")) return("Other metazoan")
  if (any(non_metazoan)) return("Non-metazoan only")
  "No informative external hit"
}

blastn_raw <- readr::read_tsv(
  blastn_file,
  col_names = hit_fields,
  col_types = readr::cols(
    qseqid = readr::col_character(),
    qlen = readr::col_double(),
    sseqid = readr::col_character(),
    staxids = readr::col_character(),
    pident = readr::col_double(),
    length = readr::col_double(),
    qcovhsp = readr::col_double(),
    evalue = readr::col_double(),
    bitscore = readr::col_double(),
    stitle = readr::col_character()
  ),
  show_col_types = FALSE
) |>
  dplyr::mutate(
    self_hit_record = stringr::str_detect(
      paste0(";", staxids, ";"), ";7010;"
    )
  )

taxonomy_lookup <- readr::read_tsv(
  taxonomy_file,
  col_types = readr::cols(
    taxid = readr::col_integer(),
    scientific_name = readr::col_character(),
    rank = readr::col_character(),
    lineage = readr::col_character()
  ),
  show_col_types = FALSE
)

blastn_external <- blastn_raw |>
  tidyr::separate_longer_delim(staxids, delim = ";") |>
  dplyr::mutate(taxid = suppressWarnings(as.integer(staxids))) |>
  dplyr::filter(!is.na(taxid), taxid != 7010) |>
  dplyr::group_by(qseqid) |>
  dplyr::mutate(
    best_external_bitscore = max(bitscore),
    external_tier_cutoff = 0.95 * best_external_bitscore
  ) |>
  dplyr::filter(bitscore >= external_tier_cutoff) |>
  dplyr::ungroup() |>
  dplyr::left_join(taxonomy_lookup, by = "taxid") |>
  dplyr::mutate(
    broad_group = classify_broad_group(lineage, scientific_name),
    gene_id = stringr::str_extract(qseqid, "^[^|]+")
  )

nucleotide_gene <- blastn_external |>
  dplyr::group_by(gene_id) |>
  dplyr::summarise(
    nucleotide_support_corrected = collapse_group_support(
      unique(broad_group)

    nucleotide_groups = paste(sort(unique(broad_group)), collapse = ";"),
    nucleotide_taxa = paste(sort(unique(scientific_name)), collapse = ";"),
    nucleotide_best_evalue = min(evalue),
    nucleotide_max_identity = max(pident),
    nucleotide_max_query_coverage = max(qcovhsp),
    nucleotide_top_tier_records = dplyr::n(),
    .groups = "drop"
  )

Interpretation and next tests

The combined audit provides four conclusions:

  1. Some unplaced scaffolds are clearly or plausibly locust-derived because they are conserved in related Schistocerca assemblies.
  2. Most of the unplaced-scaffold DEG burden is concentrated on 59 short, gene-dense scaffolds that the current Kraken2, FCS, and cross-species tests cannot resolve.
  3. Competitive mapping against Metarhizium robertsii does not by itself establish the origin of these sequences, because absence from that single fungal reference does not distinguish locust-specific sequence from another microbe, assembly artifact, or divergent sequence.
  4. The corrected BLASTn/DIAMOND analysis does not identify a near-identical non-metazoan sequence among the 948 genes. The 55 concordant non-metazoan candidates are divergent or partial at the nucleotide level and include many conserved cellular proteins. They warrant review but are not sufficient evidence for removal.

The most decisive follow-up is independent genomic evidence from the original S. gregaria assembly project: genomic DNA depth, paired-read or long-read support, and Hi-C linkage to chromosomes. For the highest-priority candidates, the next sequence-level checks are whole-scaffold BLASTn, taxon-aware read classification of reads mapping to each scaffold, GC and codon-usage comparison, and examination of whether several neighboring genes support the same taxon. Until those checks are complete, the reporting decision is placed_host_primary_unplaced_exploratory, while the biological-origin status of the unresolved genes remains retain_pending_independent_validation.
