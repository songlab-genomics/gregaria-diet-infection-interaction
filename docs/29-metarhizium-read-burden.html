Purpose

Step 1 - Count fungal alignments

Read the competitive STAR summary for each fat body library.

Step 2 - Normalize signal

Compare absolute fungal reads and their percentage of unique alignments.

Step 3 - Interpret burden

Use fungal RNA as supporting infection evidence, not as a direct biomass measurement.

Step 4 - Compare non-host composition

Use Kraken2 and Bracken to test whether retained non-host taxonomic family profiles differ among diets or treatments.

This page quantifies the RNA-seq evidence for Metarhizium robertsii in each fat body library. It uses the competitive host-pathogen alignment, in which each read is aligned against a combined Schistocerca gregaria and M. robertsii reference. This avoids counting a read independently as both host and fungus.

Two related measurements are reported:

  1. Fungal genome-mapped reads: primary, uniquely mapped read alignments assigned by STAR anywhere on the M. robertsii genome.
  2. Unique fungal alignment percentage: uniquely aligned reads assigned to the fungal reference, shown as a percentage of all unique alignments.

The first measurement is the closest available equivalent to a general “mapped reads” plot because it is not restricted to annotated exons. The percentage provides a library-normalized view of the same alignment evidence. Neither measurement is a direct measurement of fungal biomass, and matched qPCR validation was unavailable because no additional tissue remained.

Fungal genome-mapped reads

This is the broad mapping view most comparable to the previously generated “CDS alignment mapped reads” figure. Here, however, reads were aligned competitively against the complete locust and fungal genomes. The bars count primary read alignments that mapped uniquely anywhere on the fungal genome; they are not restricted to exons or CDS features.

The values will not be identical to a direct CDS alignment because the reference target, competition with the host genome, alignment algorithm, and multimapping filters differ.

Kraken2 and Bracken family composition

Competitive alignment measures reads assigned to the focal fungal reference. Kraken2 and Bracken provide a broader, complementary view of the non-host taxonomic signal. The main composition analysis uses reads that did not align to the host-only reference. This enriches microbial signal while retaining fungal reads; results from all trimmed and competitive-unmapped reads remain in the transferred taxonomy directory as sensitivity branches.

These profiles should not be described automatically as contamination. They can contain the challenge fungus, environmental or diet-associated organisms, reagent background, and taxonomic assignments caused by incomplete reference databases. Metazoan and plant families are therefore excluded from the composition display, including host-like assignments such as Hominidae. The retained profiles comprise fungi, bacteria, archaea, viruses, and other microbial eukaryotes. Relative abundance is calculated among Bracken-estimated reads assigned to these retained non-host taxonomic families, not as a percentage of the entire RNA-seq library.

read_kraken_family_lineages <- function(path) {
  fields <- strsplit(readLines(path, warn = FALSE), "\t", fixed = TRUE)
  stack <- character()
  result <- vector("list", length(fields))
  n_result <- 0L

  for (entry in fields) {
    if (length(entry) < 6) next
    rank <- trimws(entry[[4]])
    taxon_id <- trimws(entry[[5]])
    raw_name <- entry[[6]]
    taxon_name <- trimws(raw_name)
    indent <- nchar(raw_name) - nchar(sub("^[[:space:]]+", "", raw_name))
    depth <- as.integer(indent / 2)

    if (length(stack) > depth) stack <- stack[seq_len(depth)]
    stack[depth + 1L] <- taxon_name

    if (rank == "F") {
      n_result <- n_result + 1L
      result[[n_result]] <- data.frame(
        taxonomy_id = taxon_id,
        family = taxon_name,
        lineage = paste(stack, collapse = "; "),
        stringsAsFactors = FALSE
      )
    }
  }

  if (n_result == 0L) {
    return(data.frame(
      taxonomy_id = character(), family = character(), lineage = character()
    ))
  }
  dplyr::bind_rows(result[seq_len(n_result)])
}

classify_family_lineage <- function(lineage) {
  dplyr::case_when(
    grepl("(^|; )Metazoa(;|$)", lineage) ~ "Metazoa",
    grepl("Viridiplantae|Streptophyta", lineage) ~ "Plants",
    grepl("(^|; )Fungi(;|$)", lineage) ~ "Fungi",
    grepl("(^|; )Bacteria(;|$)", lineage) ~ "Bacteria",
    grepl("(^|; )Archaea(;|$)", lineage) ~ "Archaea",
    grepl("Viruses|Duplodnaviria|Riboviria|Monodnaviria", lineage) ~ "Viruses",
    grepl("(^|; )Eukaryota(;|$)", lineage) ~ "Other microbial eukaryotes",
    TRUE ~ "Other"
  )
}

Results and interpretation

The same broad family-level assignments recur across most libraries, although the absolute number of host-unmapped reads assigned by Bracken varies markedly among individuals. Diet did not explain a supported fraction of the relative family composition (R2 = 0.023, P = 0.812). In contrast, control and infected libraries differed in their multivariate taxonomic profiles (R2 = 0.115, P = 0.001), while the diet-by-infection interaction was not supported (P = 0.248). The dispersion test was not significant (P = 0.625), indicating that the treatment result was not explained simply by unequal within-group spread.

The normalized abundance of retained microbial-family assignments was also higher in infected libraries (median 54,902 reads per million input reads) than controls (median 20,458). The diet-by-infection interaction was unsupported (P = 0.369), whereas the infection effect was supported after accounting for diet (P = 0.0005). Recorded mass did not explain normalized non-host burden in the additive model (P = 0.614), and the mass-by-infection interaction remained just above the prespecified threshold (P = 0.051).

Thus, the profiles do not support a broad diet-associated restructuring of the taxonomic signal, but neither should they be interpreted as completely invariant among treatments. Because these assignments come from total-RNA libraries rather than a dedicated microbiome assay, they are best treated as supporting metatranscriptomic evidence. Individual family calls can reflect the challenge fungus, other microorganisms, residual host sequence, or database ambiguity and do not by themselves demonstrate viable colonization.
