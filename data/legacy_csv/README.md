# Legacy CSV archive

This folder keeps older CSV outputs that were useful during early exploration,
but are not the active inputs for the current workflowR analysis.

- `annotated_tables/`: older annotated DEG tables and rRNA-filtered helper tables.
- `overlap_helpers/`: older overlap/matching helper outputs used by archived Rmds or legacy scripts.

The active count matrices remain in `data/raw_read_counts/`, including the
current rRNA-filtered matrix `master_counts_no_rRNA.csv`.
